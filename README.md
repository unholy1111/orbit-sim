# 3D Orbit Simulator

This is a small project I built to simulate space in 3D using Three.js.  
It shows the Sun and the eight planets moving in real time based on basic physics.  
There’s also a built-in editor that lets you add your own planets with custom settings.

I'm still a beginner in web development, and I study at Ideal School and College.  
This project is part of my learning journey and a way to practice what I’ve been studying.

---

## Features

- Sun and 8 planets (Mercury to Neptune) included by default  
- 3D rendering with Three.js (loaded from a CDN)  
- Real-time Newtonian gravity simulation  
- Simple editor to create custom planets (mass, position, velocity)  
- Optional debug mode to see numbers and velocity vectors  
- Works best on desktop
